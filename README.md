# Lily & Light Therapy Services Website

A clean, responsive static website starter designed for GitHub Pages.

## Files

- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile navigation, year, and enquiry form
- `privacy.html` — privacy notice template
- `disclaimer.html` — website disclaimer template
- `logo.png` — supplied Lily & Light logo with transparent background
- `favicon.png` — small favicon
- `robots.txt` — search-engine crawling instructions
- `sitemap.xml` — basic sitemap template

## IMPORTANT BEFORE PUBLISHING

Replace these placeholders in `index.html`, `script.js`, and `privacy.html`:

- `YOUR_EMAIL@example.com`
- `+60 00-000 0000`
- online/in-person availability
- any service descriptions that do not exactly match the real service
- therapist name, qualifications, registration details, location and booking details

Do not publish qualifications, professional titles, registration numbers, service claims or therapeutic approaches unless they are accurate.

## GitHub Pages setup

1. Create a GitHub account if needed.
2. Create a new repository, for example: `lily-light-therapy`.
3. Upload all files in this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide the public Pages address.

## Custom domain

After buying a domain from your chosen registrar:

1. In GitHub: **Settings → Pages → Custom domain**.
2. Enter your domain.
3. At the domain registrar, add the DNS records GitHub tells you to use.
4. Wait for DNS propagation.
5. Enable HTTPS in GitHub Pages once available.

Do not copy DNS records from another website. GitHub's current Pages screen is the source of truth for the exact records required for your domain.

## SEO

Before launch:
- Use the real business location if local search is important.
- Add a real, descriptive page title and meta description.
- Add accurate therapist/service information.
- Create a Google Business Profile if appropriate.
- Submit the sitemap after the final domain is live.
- Add Open Graph/social preview information and a real social sharing image if desired.

## Contact form

GitHub Pages is static hosting, so the included form opens the visitor's email application. It does not store submissions on GitHub.

For a real web form, use a privacy-conscious form provider or a backend/booking platform and update the privacy notice accordingly. For a therapy service, avoid collecting unnecessary sensitive health information through an ordinary public form.
